# meeting-record-skill · 会议纪要生成 skill

> 给一段会议录音转写文字，直接产出**结构化会议纪要 + 行动项清单 + 老板/群同步版 + 按负责人拆分的个人待办**，共 4 份 Markdown 文件。

## 能力概览

- **输入**：一段或多段会议转写文本（支持多场会议）。
- **输出**：
  1. `会议纪要.md` — 正式结构化纪要（会议结论 / 关键讨论 / 待决策事项）
  2. `行动项清单.md` — 按会议分节的待办表格（事项/负责人/截止/验收标准/P0-P2优先级）
  3. `会议同步-老板版.md` — 精简版，可直接复制进飞书群
  4. `个人待办清单.md` — 按负责人拆分 + 本周关键节点时间线
- **质量门**：自动纠偏机制（边界检查、降级策略核对、数据准确性校验、提出人补全）。

## 典型用法

```
用户：用 meeting-record-skill 整理一下这段会议转写
（粘贴会议录音转写文字）
→ 产出 4 份 Markdown 文件，含完整纪要和行动项
```

## 结构

```
meeting-record-skill/
├── SKILL.md      # 技能定义（触发条件 + 四步流程 + 纠偏机制）
└── README.md     # 本说明
```

## 四步流程

| 步骤 | 产物 | 核心规则 |
|------|------|----------|
| ① 结构化纪要 | `会议纪要.md` | 结论/讨论/待决策 三块，每条标注提出人，数据原样保留 |
| ② 行动项表 | `行动项清单.md` | 只列明确待办，不虚构；信息缺失标"待确认" |
| ③ 群同步版 | `会议同步-老板版.md` | 开头 3 行核心结论，去内部细节，飞书友好 |
| ④ 个人待办 | `个人待办清单.md` | 按负责人拆分 + 本周关键节点按截止排序 |

详见 `SKILL.md`。
