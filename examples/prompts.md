# 使用示例 Prompts

> 这些 prompt 展示 xiaotao-illustrations 的典型用法。示例图是风格校准样例，不是构图模板。使用时应该从当前文章重新发明隐喻，不要照抄旧案例的物件和构图。

## 1. 只做配图规划（不生图）

```text
用 xiaotao-illustrations 先不要生图。
请分析下面这篇文章哪里值得配图，输出 5 张左右的 shot list。
每张图写清楚：放在哪段后、主题、核心意思、构图类型、小桃在做什么、建议中文标注词。

<粘贴文章>
```

## 2. 直接生成正文配图

```text
用 xiaotao-illustrations 把下面这篇文章生成 4 张小桃正文配图。
要求：16:9 横版、浅色水彩风、小桃轻松但严谨地承担核心动作。

<粘贴文章>
```

## 3. 为单个概念生成一张图

```text
用 xiaotao-illustrations 为"信任不是喊出来的，而是一块证据一块证据铺过去"生成一张正文配图。
小桃必须承担核心动作，编程/技术场景，隐喻要准确。
```

## 4. 为单个概念生成一张图（概念隐喻型）

```text
用 xiaotao-illustrations 为"重构是在飞行中换引擎"生成一张小桃配图。
构图类型选概念隐喻，小桃的操作逻辑要能自圆其说。
```

## 5. 为技术内容生成配图

```text
用 xiaotao-illustrations 为这段关于 CI/CD 流水线的内容生成 3 张小桃配图。
小桃要轻松但精准地搞定技术问题，画面结构与流水线逻辑一一对应。
```

## 6. 前后对比型配图

```text
用 xiaotao-illustrations 为"代码评审前后的差异"生成一张小桃配图。
构图类型选前后对比，两边差异只体现核心变化点。
```

## 7. 去掉图里的标题或错误文字

```text
用 xiaotao-illustrations 帮我编辑这张图，去掉左上角的"流程图"标题，其他内容保持不变。
```

## 8. 程序叠字（模型直绘中文错字时）

```text
这张图的中文标注有错字。用 xiaotao-illustrations 的包内字体（assets/fonts/LXGWWenKai-Regular.ttf）
把"三个断点"叠加到图右上角留白处，棕色 #8B5A3C，字号 44，轻微旋转 3 度。
```
