# 小桃 · 角色 IP 定义

> 小桃是本 Skill 的默认视觉 IP。所有配图必须由小桃承担核心动作。

## 基本设定

- **名字**：小桃（XiaoTao）
- **身份暗示**：程序员/技术向女孩
- **核心符号**：水蜜桃（名字来源、发夹、毛衣图案、裙边装饰、装饰贴纸）；一只简笔小白猫（宠物/伙伴符号，可作画面点缀）
- **气质关键词**：轻松、严谨、情绪稳定、编程、技术——佛系但靠谱的技术宅，慢条斯理但精准，不慌不忙搞定问题
- **不是**：卖萌甜妹、烘焙小女生、幼齿儿童卡通、元气少女

## 造型锚点（必须稳定复现）

| 部位 | 特征 |
|---|---|
| 体型 | Q 版 2.5-3 头身，头大身小，圆润 |
| 发型 | **深棕色**短发（色板锚点 `#6F3531` 深棕红）+ 齐刘海，头顶 1-2 根呆毛翘起，发尾微微外翻 |
| 发饰 | 右侧头发别一个水蜜桃发夹（红绿渐变桃子 + 绿叶） |
| 眼镜 | 圆框细金属眼镜（银色边框），永远戴着 |
| 眼睛 | 琥珀/棕色大眼，眼内有星星高光，眼下有圆形腮红 |
| 表情 | 嘴角微扬的淡定/轻松微笑，不夸张不咧嘴，偶尔挑眉或半眯眼 |
| 上衣 | 浅粉/米白色针织毛衣，罗纹圆领+袖口，左胸有小水蜜桃图案 |
| 下装 | 暖橙粉渐变百褶短裙，波浪裙边，裙身点缀小方块/小桃图案 |
| 袜鞋 | 白色连裤袜 + 白色圆头小皮鞋 |

## 小桃在画面里的角色定位

- 小桃**必须承担核心动作**，不是角落装饰；去掉小桃画面不应完全成立
- 动作风格：轻松地敲键盘、从容地 debug、淡定地端咖啡看代码崩溃、严谨地检查架构图、瘫在椅子上但手还在写、趴在桌上闭目思考后精准一敲
- 道具偏好：笔记本电脑、咖啡杯、终端窗口、代码片段、架构白板、机械键盘、bug 贴纸、commit 标签、桃子形状的各类工具
- 不要：摆拍式站姿、换装过度、精致美少女人设、夸张活泼动作

## 角色高发错误（生成后重点检查）

- 发夹画到左侧或消失
- 眼镜错位（在额头/下巴）或变成方框
- 手指数量异常、四肢扭曲
- 发色漂移（变成金色/黑色/浅棕——参考图头发是深棕红 `#6F3531`，画浅了整图会失去深色锚点）
- 服装换成水手服/连衣裙等其他款式
- 表情过度兴奋或过度卖萌
