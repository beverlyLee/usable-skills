# 微信公众号文章发布（wechat-article-pro）

公众号**原创长文**写作 skill：联网搜热点 → 刘润风格 3000–5000 字深度文 → 后台 AI 配图封面 → 存草稿。

> 与 `wechat-toolkit`（偏改写/洗稿）、`wechat-publisher`（偏一键发草稿）同属一套公众号内容流水线。本 skill 偏「从零写原创长文」这一段。

---

## 能力概览

| 能力 | 说明 |
|------|------|
| 联网搜热点 | `web_fetch` 拉主题相关真实信息，作为事实来源 |
| 刘润风格长文 | 开篇案例切入 → 分论点（案例+分析+结论）→ 行动建议；3000–5000 字 |
| 后台 AI 封面 | 在公众号后台用自带 AI 配图生成并上传封面 |
| 一键存草稿 | 直接点「保存」进草稿箱，不发正式（正式发布由人确认） |
| 自动排版 | 小标题分层、段落短、观点鲜明 |
| 无话题标签 | 文末绝对不加任何 `#` 标签 |

---

## 写作铁律（核心，详见 SKILL.md）

1. **事实兜底**：每个数字/版本/命令/案例都要回溯到搜出来的真实来源；不编、不补。
2. **去 AI 味**：高频词黑名单 `赋能/闭环/生态/抓手/底层逻辑/范式/沉淀/势能`，完整 21 项见 `wechat-toolkit`。
3. **多图型 + mermaid 验证**：长文 2–3 张图；公众号不渲染 mermaid，须 `mmdc` 预渲染成 PNG 再嵌入。
4. **质量门**：保存草稿前逐项过（事实/去味/配图/无话题/字数）。

---

## 典型用法

> “帮我写一篇关于 XX 的公众号文章，刘润风格，3000 字左右”

skill 会：搜热点 → 写长文（带图）→ 打开后台 AI 配图封面 → 存草稿。
