# 微信公众平台文章发布 Skill (专业版)

## 功能
1. **联网搜索热点** - 自动获取主题相关热点信息
2. **深度文章** - 撰写3000-5000字有深度的文章
3. **AI配图封面** - 使用公众号自带的AI配图功能生成封面
4. **自动上传** - 直接在公众号后台完成封面生成和上传
5. **刘润风格** - 参考刘润公众号的写作风格
6. **自动排版** - 合理的段落结构和标题层次
7. **无话题** - 文章末尾不加任何话题标签

## 写作风格参考：刘润公众号

### 刘润写作特点
1. **开篇切入**：从一个具体的商业案例、故事或现象切入
2. **引入洞察**：引出一个独特的商业观点或洞察
3. **案例论证**：用2-3个真实商业案例来论证观点
4. **数据支撑**：适当引用数据和事实
5. **结论建议**：最后给出明确的结论和行动建议
6. **语言风格**：
   - 语言简洁有力，不啰嗦
   - 逻辑清晰，层层递进
   - 很少使用emoji
   - 段落较短，每段一个观点
   - 善用小标题分隔章节
   - 观点鲜明，敢于下结论

### 结构建议
```
# 大标题（文章核心观点）

## 小标题1：第一个分论点
- 案例/故事
- 分析
- 结论

## 小标题2：第二个分论点
- 案例/故事
- 分析
- 结论

## 小标题3：第三个分论点
- 案例/故事
- 分析
- 结论

## 总结
- 核心观点回顾
- 行动建议
```

### 禁止事项
- ❌ 文章末尾禁止加任何话题标签（如 #xxx）
- ❌ 禁止使用大量emoji
- ❌ 禁止用"欢迎在评论区分享"这类话结尾

## ✍️ 写作铁律（来自 8 篇技术专栏的踩坑）

这几条是写长文时最容易翻车的地方，按优先级排：

### 1. 事实兜底（最高优先级）
- 文章里每一个数字、版本号、命令、架构名、案例，都要能回溯到 `步骤 1` 搜出来的真实来源。
- **不许编**：来源里没有的案例/数据/引言，不要为了「丰满」而补。宁可少写。
- 拿不准的结论写成「取决于 X」，不要写成定论。
- 技术文只要有一处事实错，整篇可信度归零——降重和文采都救不回来。

### 2. 去 AI 味（与 wechat-toolkit 同一套标准）
长文也必须过 de-AI。高频词黑名单（出现就改）：`赋能、闭环、生态、抓手、底层逻辑、范式、沉淀、势能`。
另避：意义膨胀句（"里程碑""深远影响"→ 具体事实）、虚假权威（"专家认为"→ 写明来源或删）、空洞结尾（"未来可期"→ 实际结论）。
完整 21 项清单见 `wechat-toolkit` 的「AI 痕迹识别清单」。

### 3. 多图型 + mermaid 验证（技术/教程类必做）
- 每篇至少 1 张图，长文 2–3 张，分散在章节间：`flowchart`（架构/流程）、`sequenceDiagram`（时序）、`mindmap`/`quadrantChart`（对比）、`stateDiagram-v2`（状态）。
- **公众号不渲染 mermaid 代码块**。发草稿前必须预渲染成图：
  ```bash
  mmdc -i diagram.mmd -o diagram.svg -p puppeteer.json   # 校验并出图
  # SVG → PNG，正文用 ![图](/绝对路径/diagram.png) 引用
  ```
- **验证纪律**：`mmdc` 必须真跑一遍。`quadrantChart` 的轴标签含中文要加引号；象限标签（`quadrant-1`..`4`）必须 ASCII，中文放 title/数据点。每张 exit 0 + 有效 SVG 才算过。

### 4. 质量门（保存草稿前逐项过）
- [ ] 每个事实都有出处，无编造
- [ ] 无黑名单高频词，无空洞结尾
- [ ] 至少 1 张图已就位（mermaid 已渲染成 PNG）
- [ ] 文末无 `#` 话题标签
- [ ] 字数 3000–5000

## 执行流程

### 步骤 1: 搜索热点
使用 web_fetch 搜索主题相关热点信息。

### 步骤 2: 写刘润风格文章
根据以下模板撰写3000-5000字文章：

**开篇**（200-300字）
- 描述一个商业现象/事件
- 引发思考

**正文**（2500-4000字）
- 3-4个小标题
- 每个小标题下：案例 + 分析 + 结论
- 案例要有细节，数据要准确
- **每个分论点配一张图**（见下方「多图型 + mermaid 验证」）

**总结**（200-300字）
- 核心观点一句话概括
- 行动建议

### 步骤 3: 打开编辑页面

1. 打开微信公众号首页：https://mp.weixin.qq.com/
2. 在首页「新的创作」下面找到「文章」
3. 点击「文章」

### 步骤 4: 输入标题
输入用户给定的主题或AI生成的相关标题。

### 步骤 5: 写正文
使用合理的小标题分层，段落简洁。

### 步骤 6: AI配图上传封面

1. **点击封面区域** - "拖拽或选择封面"
2. **选择 AI配图**
3. **输入封面描述** - 主体+场景+风格
4. **点击开始创作**
5. **等待生成**
6. **点击使用**
7. **确认封面**

### 步骤 7: 保存草稿

直接点击「保存」按钮，将文章保存到草稿箱即可。

## 注意事项

1. **必须登录** - 需要用户已登录微信公众平台
2. **AI配图需要时间** - 等待20-60秒
3. **文章字数** - 3000-5000字
4. **禁止话题** - 末尾绝对不要加任何 #标签
5. **刘润风格** - 简洁、有观点、有案例、有结论
